# Notice

## Project lineage

`dsh-wx-clawbot` is a community-maintained DeepSeek Harness (DSH) Host Bundle.
It continues the Weixin ClawBot/iLink integration started in
[zp-home/dsh-weixin-clawbot](https://github.com/zp-home/dsh-weixin-clawbot).

Primary runtime validation targets
[deepseek-harness-mobile](https://github.com/deepseek-ai/deepseek-harness) and
other DSH Web Host profiles that load Cordis bundles.
