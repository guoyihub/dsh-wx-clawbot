# 微信命令手册

[English](COMMANDS.md) | [中文首页](../README.md)

以下命令都是发送给已配对微信 ClawBot 的纯文本消息。插件命令在桥接层执行，其他
斜杠命令会尝试转交给 DSH 原生命令系统。

## 任务与诊断

| 命令 | 说明 |
| --- | --- |
| `/task` | 查看当前任务状态和已运行时间。 |
| `/queue` | 查看当前用户的排队消息和运行状态。 |
| `/cancel` | 立即请求取消正在运行的 Agent。 |
| `/steer <内容>` | 在下一个 DSH step 边界插入修正。 |
| `/doctor` | 查看已脱敏的 iLink 轮询、Outbox 和可选 DSH 能力状态。 |
| `/status` | 查看任务、会话、工作区、Preset、权限和模型。 |

普通任务默认立即回执；长任务会定时发送进度。`/cancel`、`/steer`、`/task`、
`/queue`、`/doctor`、`/approve` 和 `/reject` 绕过普通消息队列。

## 会话

| 命令 | 说明 |
| --- | --- |
| `/sessions` | 列出当前用户的未归档会话，`*` 表示当前会话。 |
| `/search <关键词>` | 按标题、完整/短 ID 或工作区搜索未归档会话。 |
| `/use <序号或短ID>` | 切换到列表中的会话。 |
| `/new [标题]` | 保留旧会话并新建会话。 |
| `/rename <标题>` | 重命名当前会话。 |
| `/archive [序号或短ID]` | 归档指定会话；不带参数时归档当前会话。 |
| `/archive-all confirm` | 归档当前用户的全部未归档会话。 |

每个授权用户最多索引 50 个会话，插件不会列出其他用户的会话。

## 运行配置

| 命令 | 说明 |
| --- | --- |
| `/model` | 查看当前模型和已注册 Provider。 |
| `/model provider/model` | 设置当前会话下一次请求使用的模型。 |
| `/preset [id]` | 查看或设置下一个新会话的 Preset。 |
| `/cwd [绝对路径]` | 查看或设置下一个新会话的工作区。 |
| `/permission` | 查看当前会话权限。 |
| `/permission workspace-write` | 使用工作区写入沙盒，并允许手机单次审批。 |
| `/permission danger-full-access confirm` | 显式授予完整机器访问，不再逐项审批。 |

Preset 和工作区属于会话创建信息，因此修改后从下一个新会话生效；权限修改对当前
会话生效。

## 手机审批

| 命令 | 说明 |
| --- | --- |
| `/approve <审批码>` | 仅允许对应的一次待审批操作。 |
| `/reject <审批码>` | 拒绝对应的一次待审批操作。 |

审批码只属于收到它的授权用户，5 分钟后失效，并且只能使用一次。超时、任务取消、
桥接停止或回复通道不可用时默认拒绝。插件只处理自己创建或恢复的 Agent；借用
Web/桌面 Agent 时，审批仍由原界面处理。

## 授权用户

| 命令 | 说明 |
| --- | --- |
| `/users` | 查看脱敏后的授权用户列表；仅主用户。 |
| `/invite` | 生成有效 10 分钟的一次性配对码；仅主用户。 |
| `/pair <配对码>` | 使用有效配对码授权当前发送者。 |
| `/revoke <序号或用户ID> confirm` | 撤销非主用户；仅主用户。 |
| `/audit [1-20]` | 查看最近的安全审计事件；仅主用户。 |

首次在本机扫码配对的账号是主用户。无效 `/pair` 不回复，避免形成授权探测接口。

## DSH 原生命令

插件不认识的命令会交给 `ctx.commands.execute()`，因此 Preset 提供的 `/plan`、
`/goal`、`/compact` 等命令仍可使用。如果 DSH 也不认识该命令，插件会明确拒绝，
不会把它当成普通提示词发送给模型。
